Privacy

For the "gog-jeanchouky" Google OAuth application.

gog-jeanchouky is a personal, single-user command-line tool. It runs on a private home server and accesses exactly one Google account: its own. No other person's Google data is requested, read, or stored.

What it accesses

  • Gmail, Google Calendar, Google Drive and related Workspace APIs of the account that authorised it.
  • Access is used to read and organise that account's own mail, events and files for a household assistant.

What it does not do

  • It does not share Google user data with any third party.
  • It does not sell data, use it for advertising, or train models on it.
  • It does not serve other users; there is no sign-up and no public service.

Storage and retention

OAuth tokens are stored encrypted on the private server that runs the tool. Data fetched from Google is processed locally and kept only as long as the task needs it. Revoking the app's access from the Google account's security settings ends all access immediately.
